The test derives aligned SFace features from the existing authorized active enrollments and current test crops. Both use the same grayscale-to-BGR, YuNet-landmark alignment and feature normalization. Existing encrypted samples are read, not rewritten. The gallery and captured frames/features remain in request memory and are not saved. Gallery features are rebuilt per request deliberately; a deployment-scale cache is outside this test-only scope.

The reference cosine cutoff is 0.363, higher is closer. Multiple qualifying identities or multiple faces selecting the same identity are rejected as uncertain. There is no LBPH fallback when SFace fails. No identity is forced to a second-best match. SFace test results describe identities observed during this capture, explicitly labeled as such. Peak simultaneous face count and peak simultaneous identity count are reported separately, so seeing people sequentially cannot be mistaken for matching them together. Completed blinks survive a brief missed detection within this request only; every new test starts fresh. A known identity can be displayed while a blink is pending; neither result creates attendance. The live LBPH flow still returns latest-frame results.
