The possible-duplicate branch previously counted repeated LBPH distance matches even when spatial face-structure comparisons failed. Repetition of a weak texture match is not independent identity evidence; with few enrolled identities it can falsely block a different person.

The shared duplicate checker now requires both qualifying LBPH distance and supporting structure evidence before counting a possible-duplicate vote. Exact encrypted-sample content hashes and the existing three-frame corroborated duplicate rule remain unchanged. The majority rule still needs at least three and 60% of accepted frames; multiple stored samples from the same identity never add extra votes for one incoming frame. Attendance recognition thresholds, database structures, school data, and the authorized photo/video rollback are unchanged.

The capture button was inspected: it clears the previous inline error, discards old frames, and captures a new dataset. It does not call recognition or duplicate matching. Duplicate validation runs on Save, or through Camera Test's enrollment checks. No UI change was needed for that behavior.

Validation: 65 isolated biometric/enrollment tests and 10 legacy smoke tests passed. Regressions cover sustained texture-only similarities below and just above the normal LBPH threshold without structure evidence, corroborated near-match rejection, exact and fresh duplicate captures, all enrolled personnel roles, multi-sample vote counting, atomic enrollment, and read-only Camera Test. All tests used synthetic data and isolated SQLite, not live student captures or Supabase writes.

Limit: This corrects an overly broad rule, not a validated identity model. Requiring corroboration can miss same-person captures with substantially changed structure. Actual Markie and friend captures have not been evaluated after the change. Test both through Camera Test enrollment mode before relying on this correction; do not claim perfect duplicate detection or change real identities to resolve a false match. No existing records or biometric files were deleted.
