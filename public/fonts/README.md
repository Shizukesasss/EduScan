# EduScan typography

Manrope is used for headings. Inter is used for body text, navigation, labels, and controls. The dense official class-record grid retains its existing Arial/Calibri stack and numeric formatting.

These variable WOFF2 files are served locally. Latin and extended Latin subsets cover the common text and accented names used in the interface. Other scripts use the operating-system fallback fonts.
